# LBLB

3D LEGO-like building game prototype.

## Stack

- TypeScript
- Three.js
- Vite
- SCSS
- WebGL

## Development

```bash
npm install
npm run dev
```

Development server runs on:

`http://localhost:4444`

## Controls

- LMB: place / select
- RMB: orbit camera
- MMB: pan
- Wheel: zoom
- Q / E: rotate brick
- Delete / Backspace: remove selected brick
- Esc: cancel placement
- Ctrl+Z: undo
- Ctrl+Y / Ctrl+Shift+Z: redo
